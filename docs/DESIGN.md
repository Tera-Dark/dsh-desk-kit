# 界面基调:极简单色「纸与仪器」

参照 [impeccable](https://github.com/pbakaus/impeccable) 的设计语言改写:
一张纸、一种墨,彩色只用来表示「失败」。这份文档是新界面的唯一口径,
改 UI 前先读这里,再动 `src/client/20-style.js` 末尾的 `3.0 单色基调` 区块。

## 三句话

1. **纸与墨,chroma 0**:所有表面和文字由宿主的两支 token 混出来,不引入第二套色板。
2. **深度只给仪器**:只有输入框、开关轨道、浮标这一类「要用手操作的东西」有内凹/描边,
   其余一律平整,分隔靠 1px 发丝线,不靠卡片、阴影和底色块。
3. **机器数据走等宽**:时间、计数、键值、节标题、路径用等宽字体 + 等宽数字;
   正文用系统无衬线。

字号档位(2026-11 上过一档,因为原来的 9~12.5px 看不清):

| 用途 | 字号 |
|---|---|
| 正文:便签、输入框、条目、卡片 | **15px**(`--dk-fs`),行高 1.6~1.7 |
| 元信息:时间、计数、标签、提示 | **12.5px**(`--dk-fs-sm`) |
| 节标题、按钮、导航 | 12.5 ~ 13px |
| 角标、极小的机器标记 | 10.5px(下限) |

功能信息不要低于 12.5px;10.5px 只留给数字角标这类「不看也懂」的东西。

## Token(全部从宿主纸墨推导)

| 名字 | 值 | 用途 |
|---|---|---|
| `--dk-paper` | `--dsw-alias-bg-layer-1` | 画布。面板、输入、格子都是这张纸 |
| `--dk-ink` | `--dsw-alias-label-primary` | 正文、主按钮底色、选中的胶囊 |
| `--dk-ink-2` | `ink 60% + paper` | 次要信息 |
| `--dk-ink-3` | `ink 42% + paper` | 元信息、占位符、节标题 |
| `--dk-rule` / `--dk-rule-2` | `ink 12% / 26%` 透明 | 发丝线 / 需要被看见的描边 |
| `--dk-wash` / `--dk-wash-2` | `ink 4% / 8%` 透明 | 悬停底、标签底、分组底 |
| `--dk-danger` | `#9b2c20` | **只有失败**:错误条、保存失败提示 |
| `--dk-mono` | ui-monospace 栈 | 机器数据 |
| `--dk-r-1/2/3` | 3 / 6 / 10px | 标签胶囊 / 卡片按钮 / 面板 |

旧名字(`--dk-brand`、`--dk-surface`、`--dk-line`、`--dk-text` …)全部指回上面这几个,
所以历史规则不用重写就会自动变成单色。

## 规矩

**要**
- 新样式只引用 `--dk-*`,不再手写 `#hex`、`rgba(...)` 或 `hsl(...)`。
- 主按钮 = 墨底纸字(`background:var(--dk-ink);color:var(--dk-paper)`);次按钮 = 描边。
- 分区头用 `--dk-mono` + `letter-spacing:.1em`;计数、时间、键值全部 `tabular-nums`。
- 列表用「一条记录 + 发丝线」,不用「一张浮起的卡」;嵌套卡片视为错误。
- 焦点环统一 `outline:2px solid var(--dk-ink)`;输入框在容器已给出焦点态时不再叠一层。
- 行内动作平时 `opacity:0`,悬停/聚焦才出现;`@media (hover:none)` 常显。

**不要**
- 不要渐变(按钮、底栏、提醒坞都不要再加)。
- 不要玻璃模糊(`backdrop-filter`)、彩色光晕、彩色阴影。
- 不要彩色胶囊、彩色角标、按域名生成的彩色格子;待办/逾期靠字重和墨色深浅表达。
- 不要让颜色表达语义(除失败);需要区分就用文字和位置。
- 不要用 11px 以下的字承载功能信息。
- 不要改布局算法和 class 契约来「顺手」做视觉调整。

## 现状与边界

- 生效的是 `src/client/20-style.js` 里最后一段 `3.0 单色基调` 覆盖层;
  1.x / 2.0 的历史视觉规则仍在文件里(最后写入者胜),清理它们是另一次独立重构。
- 改动流程不变:改 `src/client/`,然后 `npm run build`,`npm test` 会校验产物与源码一致。
- 深色宿主下自动成立:所有颜色都由 `ink`/`paper` 混出来,不假设亮色背景。
