# 安全边界(这份文档说清楚「防什么、不防什么」)

数据都在本机 `~/.dsh/desk-kit/`(默认;`DSH_HOME` 可改根目录):

```
data.json   便签、提醒、网页收藏、待确认告警(明文)
vault.json  保险库密文(AES-256-GCM)
vault.key   保险库的密钥材料(明文,与密文同目录)
blobs/      附件原件:普通附件是明文 .bin,保险库名下的是 .enc(同一把钥匙)
```

## 现在真正防住的

| 场景 | 结果 |
|---|---|
| 局域网里的其他设备 | **拿不到**。HTTP 接口只接受回环地址(127.0.0.1 / ::1),来源不是本机直接 403 |
| 你浏览的网页(含被投毒的站) | **读不到,也改不了**。读:没有 CORS 放行头,浏览器不给页面看响应;写:必须带自定义头 `x-desk-kit`,跨源想带就得先过预检,而预检我们不应答。`sec-fetch-site: cross-site` 和外部 `Origin` 也一律拒 |
| DNS 重绑定式攻击 | 现代浏览器的 Private Network Access 会挡「公网源 → 回环地址」;即便落到我们这里,来源校验仍然要求同源/本机 |
| 随手翻看 vault.json | 只有密文。字段名、标题以外都看不到内容 |
| 保险库里的截图/文件 | `blobs/*.enc` 是密文;文件名、大小、宽高在 `data.json` 里(为了列表能显示),内容看不到 |
| 有人往附件里塞 SVG/HTML 想当脚本跑 | 取件时只有图片格式允许内联,其余强制 `application/octet-stream` 下载,并带 `nosniff` + `CSP: sandbox` |
| 别的网站想直接 `<img src>` 你的附件 | 拒绝(`Cross-Origin-Resource-Policy: same-origin` + 来源校验) |
| 共享屏幕时保险库敞着 | 明文默认 30 秒自动收起;复制的密码 30 秒后自动清空剪贴板 |
| 崩溃/半截写入 | 保留 `data.json.corrupt-<时间>`,不会静默清零 |

## 现在防不住的(必须知道)

| 场景 | 为什么 |
|---|---|
| **能读 `~/.dsh/desk-kit/` 的人** | `vault.key` 就在密文旁边,拿到整个目录就能解密。「加密」在这里防的是**单文件泄漏**和**随手翻**,不防「有你这个账户的文件权限」 |
| 便签/提醒本身 | `data.json` 是明文。别把密码、身份证号直接记在便签里(说「密码是 xxx」时,一句话入口会自动送进保险库) |
| 便签里的附件 | 明文躺在 `blobs/*.bin`。截图里如果有关键信息(身份证、保单、验证码),要么放进保险库条目,要么自己注意 |
| 导出的备份 | `desk-kit-backup-*.json` **不含**附件原件;别以为导出了就全备份了 |
| 本地其它程序 | 和 DSH 同权限的进程可以读文件、也可以调 `/desk-kit-api`(只校验来源,不校验进程身份) |
| 同步盘 / 网盘 / 备份 | 如果把整个 `~/.dsh` 放进 OneDrive/iCloud/坚果云,明文便签会跟着上云;`vault.key` 也会跟着走,等于保险库一起上了云 |
| 剪贴板历史 | Windows 的「剪贴板历史」会保留复制过的密码。我们 30 秒后清「当前剪贴板」,但历史条目要你自己关(设置 → 系统 → 剪贴板) |
| 已经落盘的备份文件 | `desk-kit-backup-*.json` 里保险库是密文,但便签是明文;自己收好 |

## 想更稳一点,该做什么(按性价比排)

1. **系统盘加密**(BitLocker / FileVault):关机状态下被拿走硬盘,数据不会裸奔。
2. **不要**把 `~/.dsh` 放进同步盘。要同步就只同步导出的备份,并且知道里面便签是明文。
3. 多用户共用一台机器时,用**各自的操作系统账户**,别共用一个账户 —— 同账户下没有任何进程级隔离。
4. 敏感凭据只放保险库,不要放便签;截图前留意面板上有没有正在显示的凭据。

## 还没做、但可以做的

- **保险库口令**:用一句你输入的口令经 scrypt 派生密钥,删掉 `vault.key`,启动后要解锁才能读。这样「拿到整个目录」也解不开。代价是每次开机要输一次口令。
- **便签加密**:`data.json` 整库加密(搜索就得在内存里做),换来「文件被拷走也读不到」。

两者都还没实现 —— 现状是「够用但别高估」,上面的表就是它的真实边界。
