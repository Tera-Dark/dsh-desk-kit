# 安全边界(这份文档说清楚「防什么、不防什么」)

数据都在本机 `~/.dsh/desk-kit/`(默认;`DSH_HOME` 可改根目录):

```
data.json   便签、提醒、网页收藏、待确认告警(明文)
vault.json  保险库密文(AES-256-GCM)
vault.key   保险库的密钥材料(明文,与密文同目录)
blobs/      附件原件:普通附件是明文 .bin,保险库名下的是 .enc(同一把钥匙)
```

浏览器里还留一份**最近一次快照**(`localStorage`,键 `dsh-desk-kit/snapshot-v1`,7 天过期):
便签、提醒、网页、附件元信息与保险库的标题/合集名。它就是为了「打开秒出内容」,
**不含保险库的账号密码、正文与备注**;数据本来也会出现在界面上,清空浏览器站点数据即可抹掉。

## 现在真正防住的

| 场景 | 结果 |
|---|---|
| 局域网里的其他设备 | **拿不到**。HTTP 接口只接受回环地址(127.0.0.1 / ::1),来源不是本机直接 403 |
| 你浏览的网页(含被投毒的站) | **读不到,也改不了**。读:没有 CORS 放行头,浏览器不给页面看响应;写:必须带自定义头 `x-desk-kit`,跨源想带就得先过预检,而预检我们不应答。`sec-fetch-site: cross-site` 和外部 `Origin` 也一律拒 |
| DNS 重绑定式攻击 | 现代浏览器的 Private Network Access 会挡「公网源 → 回环地址」;即便落到我们这里,来源校验仍然要求同源/本机 |
| 随手翻看 vault.json | 只有密文。字段名、标题以外都看不到内容 |
| 保险库里的截图/文件 | `blobs/*.enc` 是密文;文件名、大小、宽高在 `data.json` 里(为了列表能显示),内容看不到 |
| 有人往附件里塞 SVG/HTML 想当脚本跑 | 取件时只有图片格式允许内联,其余强制 `application/octet-stream` 下载,并带 `nosniff` + `CSP: sandbox` |
| 别的网站想直接 `<img src>` 你的附件 | 拒绝(`Cross-Origin-Resource-Policy: same-origin` + 来源校验) |
| 共享屏幕时保险库敞着 | 明文默认 30 秒自动收起;复制的密码 30 秒后自动清空剪贴板 |
| 崩溃/半截写入 | 保留 `data.json.corrupt-<时间>`,不会静默清零 |

## 现在防不住的(必须知道)

| 场景 | 为什么 |
|---|---|
| **能读 `~/.dsh/desk-kit/` 的人** | `vault.key` 就在密文旁边,拿到整个目录就能解密。「加密」在这里防的是**单文件泄漏**和**随手翻**,不防「有你这个账户的文件权限」 |
| 便签/提醒本身 | `data.json` 是明文。别把密码、身份证号直接记在便签里(说「密码是 xxx」时,一句话入口会自动送进保险库) |
| 便签里的附件 | 明文躺在 `blobs/*.bin`。截图里如果有关键信息(身份证、保单、验证码),要么放进保险库条目,要么自己注意 |
| 导出的备份 | `desk-kit-backup-*.json` **不含**附件原件;别以为导出了就全备份了 |
| 本地其它程序 | 和 DSH 同权限的进程可以读文件、也可以调 `/desk-kit-api`(只校验来源,不校验进程身份) |
| 同步盘 / 网盘 / 备份 | 如果把整个 `~/.dsh` 放进 OneDrive/iCloud/坚果云,明文便签会跟着上云;`vault.key` 也会跟着走,等于保险库一起上了云 |
| 剪贴板历史 | Windows 的「剪贴板历史」会保留复制过的密码。我们 30 秒后清「当前剪贴板」,但历史条目要你自己关(设置 → 系统 → 剪贴板) |
| 已经落盘的备份文件 | `desk-kit-backup-*.json` 里保险库是密文,但便签是明文;自己收好 |
| 浏览器配置目录 / 本地存储 | 为了首屏秒开,最近一次快照(不含保险库明文)会在 `localStorage` 里放 7 天;共用系统账户的人能从这里看到便签标题 |

## 主动网络请求(粘贴网页图片)

从 1.21 起,如果剪贴板里只有网页图片地址,浏览器半侧会让宿主下载后落盘:

- 只接受 `http/https`,拒绝 `localhost`、回环和私网**字面地址**;
- 重定向最多 4 跳,每一跳重新校验;
- 单张最多 24MB,10 秒超时,内容类型必须是 `image/*`;
- 下载后的图片按普通附件落在 `blobs/*.bin`(明文);放进保险库条目才会加密。

**仍有的风险**:目前只校验 URL 的主机名,没有在 DNS 解析后再核对目标 IP。如果攻击者控制一个公网域名并把它解析到内网地址,理论上仍可能触发内网请求;需要更强隔离时应再加解析后 IP 校验或出站代理。

## 想更稳一点,该做什么(按性价比排)

1. **系统盘加密**(BitLocker / FileVault):关机状态下被拿走硬盘,数据不会裸奔。
2. **不要**把 `~/.dsh` 放进同步盘。要同步就只同步导出的备份,并且知道里面便签是明文。
3. 多用户共用一台机器时,用**各自的操作系统账户**,别共用一个账户 —— 同账户下没有任何进程级隔离。
4. 敏感凭据只放保险库,不要放便签;截图前留意面板上有没有正在显示的凭据。

## 还没做、但可以做的

- **保险库口令**:用一句你输入的口令经 scrypt 派生密钥,删掉 `vault.key`,启动后要解锁才能读。这样「拿到整个目录」也解不开。代价是每次开机要输一次口令。
- **便签加密**:`data.json` 整库加密(搜索就得在内存里做),换来「文件被拷走也读不到」。

两者都还没实现 —— 现状是「够用但别高估」,上面的表就是它的真实边界。

## 2026-11-22 复查(1.31.1)

这一轮把「谁能调接口 / 谁能出网 / 谁能把内容当脚本跑」三条线重新过了一遍。

### 复查确认没问题的

| 面 | 结论 |
|---|---|
| 路由鉴权 | `isLoopback` 只认 `127.0.0.1` / `::1`;`guardRequest` 同时看 `Host`(挡 DNS rebinding)、`sec-fetch-site`、`Origin`,写操作还要求自定义头 `x-desk-kit` |
| 附件取件 | URL 里的 id 只在 `data.files` 里查表,并过 `isBlobId` 才拼路径 —— 不存在路径穿越 |
| 附件当脚本跑 | 只有 6 种图片 MIME 内联,其余 `octet-stream` + `attachment`,附 `nosniff`、`CSP: sandbox; default-src 'none'`、`CORP: same-origin` |
| 备份导入 | 必须带 `kind: dsh-desk-kit-backup` + `version: 1`;每类条目先过 `normalize*` 白名单重建,坏条目计数跳过;`replace` 模式先写 `data.json.before-import-*` 回滚文件,写不出就拒绝替换 |
| 保险库加密 | AES-256-GCM,每条独立 12 字节随机 IV + authTag;密钥 = scrypt(随机 48 字节 hex 材料,随机 salt) → 32 字节;`vault.key` 0644→0600 |
| 反射注入 | 客户端没有 `dangerouslySetInnerHTML`;网页/提醒的 url 只接受 `^https?:` 并归一化,`javascript:` 进不来 |
| 命令执行 | 没有 `child_process` / `eval` / `new Function` |
| 用户输入当正则 | 没有 `new RegExp(用户输入)`,不存在 ReDoS |
| 落盘一致性 | `writeJson` 先写 `.tmp-<pid>-<rand>` 再 `rename`,崩溃不留半截;读坏文件先另存 `.corrupt-<时间>` |

### 已知残余风险(接受,但要清楚)

| 风险 | 说明 |
|---|---|
| 粘贴图片的 SSRF | 已加 DNS 解析检查,但解析与 fetch 之间仍可被换记录(TOCTOU)。彻底解决要「解析出 IP 后直连该 IP 再带 SNI」,代价与收益不成比例 |
| fake-IP 代理会让 DNS 检查失效 | Clash/Surge 把域名全解析到 198.18/15,此时只剩字面量 IP 与主机名黑名单在挡 |
| 同源页面/其它插件 | 任何跑在 DSH web 源里的页面(包括渲染 HTML 的插件)都满足「同源 + 能带 `x-desk-kit`」,可以直接调接口读保险库。desk-kit 无法区分「自己人」和「同源的别人」 |
| 附件 MIME 由上传方声明 | `x-file-name` 与 `content-type` 都来自调用方;取件时的强制下载头兜住了后果 |
| 导入条目可携带额外字段 | `normalize*` 用 `...raw` 打底再覆盖白名单字段,未知字段会跟着存进 `data.json`(不会被当作逻辑使用) |
